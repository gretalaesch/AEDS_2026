# Alaska Environmental Data Science

This repository contains my independent environmental data
science coursework during my Alaska Climate Adaptation Science
Center fellowship.

The curriculum focuses on environmental data science using
real Alaska datasets, with particular emphasis on climate,
geospatial data, statistical learning, and energy systems.

## Goals

1. Have good Git practices, be able to work with a team using Git workflows
2. Apply statistical learning concepts to Alaska climate data
3. Gain an understanding of how to use different data structures
4. Raster and vector analysis
5. SQL basics and spacial databases 
6. Identify interest areas in environmental data science
